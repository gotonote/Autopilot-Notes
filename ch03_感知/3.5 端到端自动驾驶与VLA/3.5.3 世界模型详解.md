# 世界模型详解

> 世界模型（World Model）：让模型学习**环境的动态规律**，能够预测"如果采取某动作，未来会发生什么"。在自动驾驶中，世界模型是端到端感知、预测、规划之外的"能力倍增器"——它提供预测、仿真、数据生成与闭环训练能力，是当前与 VLA 并列的第二条技术主线。

---

## 一、什么是世界模型

### 1.1 定义

世界模型是一类学习**环境状态转移规律** $P(s_{t+1} | s_t, a_t)$ 的模型：给定当前状态（多传感器观测）和候选动作，预测未来状态（下一帧图像、Occupancy、场景演化）。

```
当前观测(图像/点云/BEV) ─┐
                        ├─▶ 世界模型 ──▶ 未来帧/未来场景/未来轨迹
候选动作/自车控制 ──────┘
```

与生成模型（如扩散模型画图）的区别：世界模型的核心是**在动作条件下的环境动态建模**，输出用于驾驶决策，而非单纯内容生成。

### 1.2 为什么需要世界模型

| 痛点 | 世界模型的解法 |
|:-----|:-------------|
| 端到端只学"像素→动作"统计映射，缺因果推理 | 世界模型显式建模环境动态，学会"如果…就…" |
| 模仿学习分布偏移（训练数据覆盖不足） | 在模型想象空间中做闭环训练/强化学习，探索更多状态 |
| 长尾场景数据稀缺 | 用世界模型生成合成场景/未来帧，扩充训练数据 |
| 规划难以评估"如果走这条路会怎样" | 世界模型支持多假设推演（mental simulation） |
| 仿真器与真实世界 gap 大 | 数据驱动的世界模型作为"可学习仿真器" |

## 二、技术分类

### 2.1 按输出形式分类

| 类型 | 输出 | 代表 |
|:----:|:-----|:-----|
| **视频预测类** | 未来帧图像/视频 | GAIA-1、DriveDreamer、NVIDIA Cosmos、GenAD |
| **场景表示类** | 未来 Occupancy/栅格/BEV | DriveWorld、OccWorld |
| **轨迹/状态类** | 未来场景内目标轨迹与状态 | Waymo 内部模型、Hybrid 方案 |
| **隐空间类** | 潜在状态（latent）上的转移 | Dreamer、IRIS（强化学习派） |

### 2.2 按学习范式分类

- **自监督视频预测**：只看大量驾驶视频学习动态（无需标注，GAIA-1、Cosmos）
- **动作条件生成**：给定动作序列预测未来，用于"如果规划"推演（GenAD）
- **与 VLA/端到端融合**：世界模型为 VLA 提供想象空间与预测先验（DriveWorld-VLA、华为 WEWA）
- **强化学习世界模型**：在想象空间中训练策略（Dreamer 系）

## 四、世界模型的能力与用途

### 4.1 四大核心能力

1. **预测**：预测自车周围环境的未来演化（障碍物运动、道路拓扑变化），为规划提供前瞻
2. **生成仿真**：作为数据驱动的可学习仿真器，比规则仿真器更真实、覆盖更广
3. **数据增强**：生成长尾场景（极端天气、事故现场、罕见交互），缓解数据稀缺
4. **闭环训练**：在想象空间中让策略模型交互试错（RL 训练），弥补真实数据不足

### 4.2 在系统中的作用

```
                    ┌──────────────┐
                    │   世界模型    │◀── 预测/推演/生成/训练
                    └──────┬───────┘
                           │ 想象空间/预测先验
   传感器 ──▶ 感知/编码 ──▶ VLA 推理 ──▶ 规划/动作 ──▶ 控制
                           ▲
                    ┌──────┴───────┐
                    │ 闭环训练/仿真 │
                    └──────────────┘
```

## 五、训练与数据

- **数据来源**：大规模无标注驾驶视频（自监督）、真实交互数据、仿真数据
- **训练目标**：视频重建/预测损失、动作条件一致性、Occupancy 未来状态预测
- **关键难点**：
  - **多模态对齐**：图像/点云/BEV/文本多模态输入到统一世界表示
  - **长时间一致性**：预测未来 5~10 秒的场景一致性（物体不漂移、场景不崩坏）
  - **动作条件解耦**：模型需区分"自车动作导致的变化"与"环境自身演化"
  - **算力**：生成式模型训练与推理成本高，车端需蒸馏轻量化

---

## 六、挑战与展望

### 主要挑战

- **预测可靠性**：生成的未来不一定真实，错误预测会误导决策（需要不确定性估计）
- **评估体系缺失**：视频生成质量指标（FVD 等）与驾驶安全无直接映射
- **算力与时延**：生成式推理开销大，难以实时车端部署
- **长尾覆盖**：模型对训练分布外场景的想象可能失真

### 展望

- **世界模型 + VLA 深度融合**：世界模型提供想象空间，VLA 提供语言推理，二者互补（DriveWorld-VLA、WEWA 方向）
- **端侧轻量化世界模型**：从云端生成走向车端实时预测
- **统一"预测-规划-训练"范式**：世界模型成为端到端系统的统一底座，替代规则仿真器
- **评测体系**：构建"场景演化正确性 + 闭环安全指标"的世界模型基准
